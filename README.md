# 829 Authentication Plugin

A WordPress plugin that integrates WorkOS SSO for seamless Okta authentication.

## Features

- Single Sign-On (SSO) via WorkOS
- Okta integration
- Just-in-Time (JIT) user provisioning
- Dynamic role assignment based on Okta groups
- WordPress admin settings interface

## Requirements

- PHP 7.4 or higher
- WordPress 5.0 or higher
- Composer for dependency management
- WorkOS account and credentials
